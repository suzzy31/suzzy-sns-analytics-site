Privacy Policy

Last updated: October 16, 2026

1. Current status

SUZZY SNS Analytics is in development. This informational website does not currently provide TikTok login, request TikTok permissions, or automatically retrieve TikTok data. The practices below describe the planned integration and must be reviewed before it is activated.

2. Intended information

After the account owner authorizes access, the planned tool may process the minimum account identifiers and public-video performance information permitted by the approved TikTok scopes, potentially including video IDs, captions, view counts, likes, comments, and shares. It is not designed to collect TikTok passwords.

3. Purpose and processing

Authorized information would be used to organize the owner's video performance, create reports, and support content planning. The intended workspace is a privately controlled Google Sheets document and associated Google Apps Script project.

4. Access and sharing

Access is intended to be limited to the account owner and systems needed for processing. No sale of TikTok data or advertising profiling is intended. Google services and TikTok may process information under their respective terms when the integration is enabled.

5. Security and retention

Any future access tokens should be stored outside public source code and access restricted to the owner. Retention and deletion controls must be finalized and implemented before public operation. The owner should be able to revoke TikTok authorization and request removal of stored analytics data.

6. Contact and requests

For general questions or a request to arrange data deletion, contact the project through GitHub Issues. Do not include credentials or personal details in a public issue. A private communication method must be established for any request involving sensitive information.

7. Changes

This policy will be updated before live integration if collection, storage, contact, or deletion practices change.
