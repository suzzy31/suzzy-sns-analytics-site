SUZZY SNS Analytics

A personal analytics project for organizing performance information from an authorized TikTok account in Google Sheets, to help review content and improve future posts.

Status

The integration is under development. TikTok account authorization and automatic data retrieval are not yet active. This website explains the intended use and applicable policies.

How it is intended to work

The account owner authorizes access to supported TikTok account and public-video information. The tool then organizes permitted metrics such as views, likes, comments and shares for private reporting. The account owner remains responsible for publishing content.
